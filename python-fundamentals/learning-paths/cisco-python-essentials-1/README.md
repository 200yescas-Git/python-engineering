# Python Essentials 1

## Overview

Esta ruta de aprendizaje está basada en el programa **Python Essentials 1** de **Cisco Networking Academy**, orientado al desarrollo de competencias relacionadas con los fundamentos del lenguaje Python, la lógica de programación y la construcción de programas mediante buenas prácticas de desarrollo.

Su propósito es proporcionar una base sólida para comprender los conceptos esenciales del lenguaje Python y preparar el camino hacia niveles más avanzados de programación y automatización.
