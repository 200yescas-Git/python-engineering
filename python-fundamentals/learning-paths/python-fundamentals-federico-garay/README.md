# Python Fundamentals — Federico Garay

## Overview

Esta ruta de aprendizaje está basada en el curso **Python Fundamentals** impartido por **Federico Garay**, orientado al desarrollo de competencias relacionadas con los fundamentos del lenguaje Python, la lógica de programación y la resolución de problemas mediante programación.

Su propósito es proporcionar una base sólida para el aprendizaje de Python y servir como punto de partida para especializaciones posteriores en automatización, desarrollo de software, ciencia de datos, inteligencia artificial, DevOps y ciberseguridad.
