# Python Essentials 2

## Overview

Esta ruta de aprendizaje está basada en el programa **Python Essentials 2** de **Cisco Networking Academy**, orientado al desarrollo de competencias relacionadas con programación intermedia utilizando Python, programación orientada a objetos, manejo de excepciones, módulos y buenas prácticas para el desarrollo de aplicaciones.

Su propósito es fortalecer los conocimientos adquiridos en Python Essentials 1 y desarrollar habilidades necesarias para construir aplicaciones más estructuradas y escalables.

---

## Objective

El objetivo de esta ruta de aprendizaje es desarrollar competencias relacionadas con:

- Intermediate Python Programming.
- Object-Oriented Programming.
- Modular Programming.
- Exception Handling.
- File Management.
- Programming Best Practices.
