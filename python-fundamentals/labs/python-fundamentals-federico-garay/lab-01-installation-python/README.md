# Installation - Python

## Objective

Realizar la instalación del lenguaje de alto nivel python para llevar acabo la habilidad de desarrollar nuestro código en diferentes proyectos del desarrollo de software. Además de su instalación solamente se llevará acabo una vez, por lo que para futuras certificaciones o cursos ya tengamos nuestro entorno de laboratorio en status activo y continuo desarrollo.

## Installation Python - PyCharm

### Python

- Descargar Python en su página oficial
- Seleccionar la sección Downloads para revisar los paquetes de instalación
- Seleccionar el paquete base al sistema operativo
- Ejecutar el asistente de instalación
- Seleccionar Installation Now
- Cerrar la ventana una vez finalizada la instalación

### Pycharm

- Descargar PyCharm en su página oficial
- Dar clic en descargar seleccionado el archivo ejecutable ( executed )
- Iniciar asistente de instalación
- Aceptar términos de instalación para empezar el proceso
- Seleccionar una ruta para su instalación
- Agregar opciones como la extensión de archivos python y editores de texto
- Iniciar el proceso para finalizar y empezar a programar código
